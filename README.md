# Sales & Profitability Performance Dashboard

- This project aims to analyze the sales performance of AdventureWorks. It is an interactive dashboard developed to monitor key business metrics such as sales, profit, margin, performance by product category, region, and time trends. It demonstrates the practical application of data modeling, DAX measures, and analytical visualization techniques, transforming raw data into actionable insights with a strong focus on data storytelling and business intelligence.

- The dashboard was developed in Power BI, with a interactive look, allowing dynamic filters to support strategic decision-making.
